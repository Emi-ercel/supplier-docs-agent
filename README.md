# supplier-docs-agent

A Claude agent that answers food-quality questions about supplier documents, knows when to refuse, and is evaluated on every change.

> **Status: work in progress (v0 planned for November 2026).** The synthetic dataset is in place; the MCP server, the agent and the eval suite are being built in the open. See the [issues](../../issues) for the roadmap.

## Why this exists

Quality departments in food companies spend a lot of time answering the same questions: *Is this supplier's IFS certificate still valid? Does product P-1004 contain allergens? Did lot L2605-0012 pass its histamine limit?* The answers live in structured records and in documents.

This repository builds an agent for that job and measures it honestly. It tests one specific claim from a real deployment: **tools that look records up by identifier are more reliable than searching a document index.** The same question bank runs against both setups, and the results are published here.

## What is in the box (planned for v0)

| Piece | What it does | Status |
|---|---|---|
| Synthetic dataset | 20 suppliers, 60 products, certificates and lots for *Huerta Norte S.L.*, a fictional canner | ✅ |
| MCP server | Exposes lookup tools (`get_product_sheet`, `get_certificate`, `get_lot`, …) and `search_documents` | ⏳ |
| Agent | A tool-use loop on the Claude API that answers in JSON `{answer, sources, refused}` | ⏳ |
| Eval suite | 40 questions with known answers, including traps where the right answer is to refuse | ⏳ |
| CI | Tests on every push; the eval suite on every pull request, failing on regressions | ⏳ |

## Quickstart

Requires [uv](https://docs.astral.sh/uv/) and Python 3.12.

```bash
uv sync
uv run generate-data   # regenerates data/ (deterministic)
uv run pytest
```

## Data

All data is invented and generated by [`src/supplier_docs/generate.py`](src/supplier_docs/generate.py) with a fixed seed. Any resemblance to real companies is coincidental. `data/dataset.json` holds the records; `data/documents/` holds the same information rendered as Markdown documents for the search tool.
